# 城市内涝快速预测模型发布说明

本仓库对应论文：

> Li, R., Huang, Z., Dong, Y., Hu, Q., Dong, X., & Zhong, L. (2026). A mechanism-data hybrid pretraining-finetuning framework for rapid and reliable urban pluvial flooding prediction. *Water Research*, 305, 126491. https://doi.org/10.1016/j.watres.2026.126491

## 论文简介

本研究针对城市内涝高精度水动力模型计算成本高、纯数据驱动模型又高度依赖大规模高质量观测的矛盾，提出了一套机理—数据融合的预训练—微调快速预测框架。该方法首先利用随机化环境情景、SWMM–CADDIES机理模拟结果及质量与动量守恒等物理约束学习可迁移的水动力先验，再结合有限的监测与多源观测数据进行本地微调，从而兼顾积水演化的物理合理性、局地预测精度与计算效率。案例结果表明，该模型能够较好刻画城市内涝从积水形成、发展到消退的时空过程，在监测点取得较高预测精度，并显著降低在线推演时间，为观测稀缺条件下的城市内涝快速预测、实时预警和应急响应提供了一种可行的技术路径。


## 发布范围

本 Git 仓库公开说明文档及加密模型压缩包。
作者保存的两个原始 PyTorch checkpoint 为：

- `pretrain_wr.pth`：机理信息预训练后的模型；
- `finetune_wr.pth`：观测数据微调后的模型。

`.pth` 为依赖私有网络结构的 `state_dict`。在不公开架构源码的情况下，使用者应优先使用与模型版本严格匹配、经审批提供的 TorchScript 生成器模型（`*.ts`）。公开输入输出接口见 [MODEL_USAGE.md](MODEL_USAGE.md)。

## 方法与环境条件张量

根据论文补充材料，环境条件张量由以下 11 个通道组成：累计降水量、平均降水强度、最大降水强度、径流系数、调蓄容量、高程（DEM）、坡度、地形湿度指数（TWI）、水流功率指数（SPI）、管网容量密度和道路密度。

11 个环境变量共同构成 U-Net 生成器的条件输入。生成器采用 64-128-256-512-1024 的编码路径、对称解码路径和跳跃连接，PatchGAN 判别器用于约束下一时刻积水深度场的局部空间真实性。

预训练阶段使用随机环境情景以及 SWMM-CADDIES 耦合模型产生的教师信号，并结合物理约束与知识蒸馏；微调阶段使用稀疏观测进行本地适配。

## 图像水位识别

本研究还包含从社交媒体图像中提取城市内涝观测信息的水位识别流程。首先使用 YOLOv9 检测具有相对标准尺寸的参照物，包括车辆轮胎和人体部位，并确定关键位置与水面的相对关系；随后结合轮胎规格以及补充材料中的人体部位—水深映射关系推算积水深度。

对于缺少清晰参照物的图像，使用紧凑型两层 CNN 将水深划分为 `(0, 10]`、`(10, 20]`、`(20, 30]` 和 `(30, 40]` cm 四个等级。训练过程包含图像归一化和数据增强，评价指标包括 top-1 分类准确率与平均类别距离。识别结果仅与文本、POI、路牌、建筑、车站或其他可见地理证据支持的位置关联，不使用用户 IP 地址推导坐标。

模型压缩包包含四级图像分类权重 `water_level_cnn.ckpt`、人体参照物检测权重 `human_reference_detector.pt`，以及车轮淹没水位分类权重 `wheel_water_level_cnn.ckpt`。车轮模型的六个类别标签为 `0`、`10`、`20`、`30`、`40` 和 `50` cm。

## 社交媒体文本处理

文本流程对微博、抖音和小红书帖子进行城市内涝相关性筛选，并通过语言模型 API 提取事件时间、地点表达及证据文本、`30 cm` 等定量水深、`水到脚踝` 或 `水到膝盖` 等定性水深，以及各项结果对应的原文证据。定量值统一换算为米，人体部位描述根据补充材料中的对应表映射为水深。

地点证据按具体程度分级。具有 POI、道路交叉口、车站、建筑、地标、街道或社区级描述的记录，可根据质量等级进入空间分析；证据不足的记录不进入点位验证。流程不会推断原文中缺失的水深、地点或坐标。文本处理在运行时调用兼容的语言模型 API，不需要单独的本地 checkpoint。
